# 拾藏 · 抖音收藏整理与问答

在本机网页中扫描“收藏－视频”里的视频与图文，使用 OpenAI 兼容模型生成分类和收藏夹名称，预览后执行整理。

也可以在“收藏问答”中提问：本机转写视频语音、建立中文检索索引，再由你配置的模型根据相关片段回答。支持连续追问、历史对话、视频来源、转写原文和时间位置；没有足够依据时明确提示。分类与问答沿用同一套模型服务配置。

## 启动

需要 Python 3.12+、uv，以及本机 Microsoft Edge（Windows 默认使用）。

```powershell
uv sync --frozen
uv run --frozen douyin-rag
```

打开 <http://127.0.0.1:8765>。更换端口：`uv run --frozen douyin-rag --port 8767`。仅监听本机，不需要注册网站或发布到云端。

在网页点击“查看示例”可以体验分类、筛选、改名和批量调整。示例模式不会向抖音发起写入。点击“使用我的收藏”后再连接真实账号。

## 使用步骤

1. **连接与设置**：填写 OpenAI 兼容服务地址、模型名、API 密钥。地址可为服务的 `/v1` 基础地址或完整 `/chat/completions` 地址。本机免密服务可不填密钥。
2. **连接抖音**：点击“扫码登录”，当前设置页会展示真实抖音登录页中的二维码，本机浏览器在后台运行，不弹出额外窗口。用抖音 App 扫码并在手机上确认后，应用检测到会话 Cookie 就自动保存登录状态并关闭后台登录浏览器，可以直接使用收藏功能，不再额外请求收藏接口来验证登录。二维码过期可以刷新。也可填写已有 douyin-mcp 的外部登录状态文件路径；此时以显式配置为准，扫码后如想改用本应用会话，请清空外部路径再保存。
3. **扫描收藏**：遍历全部收藏、收藏夹和夹内作品，按作品 ID 去重并记录原归属。中途失败不会覆盖上次完整快照。
4. **生成分类方案**：模型先根据均匀采样的全量标题设计分类，再逐批给每条作品归类。当前依据标题、描述与作者信息，不下载视频、转写语音或 OCR。内容不足会进入“待复核”或标记低置信度，不声称已经观看内容。
5. **预览**：查看分类依据；修改每条作品的目标分类或收藏夹名称；支持多选批量调整。尚未返回有效结果的作品显示“待分类”。不完整的模型批次不会写入方案。
6. **确认并整理**：先安装并打开 Ego Lite，确认 `ego-browser` 命令可用，并在 Ego Lite 登录与扫描时一致的抖音账号。确认方案后，应用会在 Ego Lite 打开拾藏整理页面，查询或通过网页接口创建私密目标夹，再按目标夹分批移入。首批最多 3 条，确认多条作品都已进目标夹后，每批最多 10 条。移入批次串行执行，间隔取操作间隔与 5 秒中的较大值。暂停后可以继续，续跑会按夹读取当前成员，跳过已经移入的作品。
7. **核对结果**：移入请求处理完后按目标收藏夹统一核对，分页按游标顺序读取。只有确认作品已进目标夹，才会清理并核对旧归属。原收藏夹和作品的收藏状态会保留。重新扫描或分类会将旧快照和方案归档，可在“整理记录”导出。

“全量”指平台实际返回的全部可读作品。隐藏、删除等不可读条目的原始分页提示单独保存；不把可读数量当成账号总收藏数，也不盲目累加可能在多页重复的无效条目数。

## 收藏问答

1. 完成抖音登录并扫描收藏，然后打开“收藏问答”。分类与移动收藏夹不是问答的前置条件。
2. 点击“处理视频内容”。应用即时读取视频详情和媒体地址，临时下载视频，在本机用 `faster-whisper` 的 CPU INT8 模式转写，保留时间戳。处理完当前作品后临时媒体自动删除。
3. 转写按原有语音片段分段，由 `BAAI/bge-small-zh-v1.5` 本机向量模型建立索引。检索结合语义相似度与中文关键词；标题和作者只作为来源信息，不充当视频正文。
4. 处理进度按作品保存。暂停在当前作品处理结束后生效；再次点击处理或继续任务会跳过已完成作品，重试失败作品。新增收藏扫描后只处理尚未建库的作品。切换转写模型后会重新处理，旧快照和当前收藏之外的作品不会进入本次检索。
5. 在连接与设置中填写模型服务地址、名称和 API 密钥后提问。问答向该服务发送当前问题、近期问题和相关文字片段，不发送视频音频。回答会列出来源和时间位置，点击“打开原视频”可回到作品页面；时间位置显示在本应用内，不保证抖音网页支持跳到该秒数。
6. 追问沿用当前对话；用“新对话”开启其他主题，或从对话下拉框恢复历史。历史保存在本机并按扫描账号隔离，不依赖浏览器临时存储。

默认 `small` 模型下载约 486 MB；`base` 约 148 MB，可在设置中切换。本机中文向量模型另需约 90 MB；这些是模型文件大小，不包含 Python 依赖与缓存占用。首次使用需要联网下载公开模型，不需要注册转写账号，也不需要安装系统 FFmpeg 或 CUDA；后续使用缓存。网络不可达时会保留进度并报错，可以在网络恢复后重试。

首版处理视频中的可识别语音，不提取画面字幕、不做 OCR、图文识别或无声演示理解。单条视频上限为 60 分钟、256 MiB。语音识别可能受口音、背景音乐和术语影响，重要内容应核对原视频。媒体接口非官方，删除、私密、登录失效、媒体地址域名变化或风控都可能导致失败。界面分别统计已可问答、待处理、失败和暂不支持的作品，不将“任务结束”当作“所有视频成功”。

“体验合成示例”使用独立的合成转写，演示关键词检索、追问、来源与历史，不下载媒体、不加载本机模型、不调用云端服务；示例视频不提供伪造的真实链接。

## 本机配置与数据

默认运行目录是 Windows 的 `%LOCALAPPDATA%/douyin-rag`，其他系统为 `~/.local/share/douyin-rag`。可通过 `DOUYIN_RAG_STATE_DIR` 自定义。

- 模型设置、密钥、扫描快照、方案和进度写入运行目录，不进入 Git。模型密钥存于本机设置文件，未加密；若不希望落盘，可以使用环境变量。接口和导出的记录均不返回密钥。
- 登录沿用 `DOUYIN_COOKIE`、`DOUYIN_COOKIE_PATH`，或 `XDG_CONFIG_HOME/douyinmcp/cookies.txt`（未配置 XDG 时为 `~/.config/douyinmcp/cookies.txt`）；也支持本应用扫码后的独立浏览器会话。
- `DOUYIN_RAG_API_BASE`、`DOUYIN_RAG_MODEL`、`DOUYIN_RAG_API_KEY` 可提供或覆盖模型配置。不要把真实值放进仓库或粘贴到聊天中。
- `DOUYIN_RAG_BROWSER` 可指定已安装 Chromium 系浏览器的可执行文件；未使用本机 Edge 的环境可运行 `uv run playwright install chromium`。
- 浏览器配置、登录状态文件、模型请求正文不会出现在导出和应用访问日志中。收藏快照本身包含个人收藏信息，按需自行保管。
- `knowledge.sqlite3` 保存转写、片段、向量与聊天记录，`models/` 保存模型缓存，都位于上述运行目录，按扫描账号隔离。现有“导出记录”仍只导出收藏整理记录，不包含知识库和聊天记录。本机数据库及历史记录未加密，请按个人数据保管。
- 本地转写不会上传音频，但云端问答会收到问题和相关转写片段。首次启用问答前，应选用你愿意向其发送这些文字的模型服务。模型内的提示注入防护与引用编号校验不能保证每个自然语言结论完全正确，重要结论应核对展示的原文。

## 写入范围与验证限制

读取复用 douyin-mcp 的 HTTP 客户端协议、本地签名和响应校验，扫码与外部 Cookie 均走同一条收藏读取链路。扫码浏览器的 User-Agent 与读取客户端保持一致，登录后提取抖音域及其子域的 Cookie。二维码仅从登录页指定元素截取，在本机页面展示，不写入项目、导出或日志。Ego Lite 在已登录抖音页面内发送建夹和移动请求，再由本机扫描会话读取并核对结果。Ego Lite 的登录凭据留在该浏览器内，每次写入前会校验会话指纹。

这是非官方网页接口。接口协议变化、验证码、会话失效或风控都可能中止操作。如果 Ego Lite 提示登录或验证，在该整理页面处理后点击「继续整理」。若无法确认 Ego Lite 的会话与扫描快照一致，应用会停止写入。接口拒绝、超时和核对失败时会保留进度，续跑会先查询抖音。自动化测试使用模拟抖音与模型服务。

## 验证与构建

```powershell
uv run --frozen python -m unittest discover -s tests -v
node --check web/app.js
uv build
```

测试覆盖收藏分页/去重、图文、超长 ID、签名运行时、无效作品提示、模型异常与断点续分、方案修订、账号变化、移动写后核对、进度恢复、归档、密钥脱敏及本机请求边界。不使用真实生产凭据或真实收藏进行测试。

问答测试还覆盖媒体地址和重定向限制、下载大小上限、带时间戳转写、分段、增量处理与重试、账号隔离、移出收藏后的检索过滤、追问、历史恢复、引用编号校验、无依据拒答和示例模式不调用模型。依赖中的 `av==16.1.0` 固定为已验证兼容版本，避免新版移除解码参数造成转写失败。

## 代码范围

- `collections.py`：按函数提取的收藏读取与作品整理。
- `signing.py`、`verification.py`、`assets/abogus.js`：读取所需的签名与校验；签名脚本移除了无关前置补丁和演示查询。
- `organizer.py`：扫描、OpenAI 兼容分类、方案编辑、状态与归档。
- `writer.py`：本机浏览器扫码登录。
- `ego_writer.py`：Ego Lite 会话接入、建夹、移动与核对。
- `app.py`、`web/`：本机 API、网页及静态资源。
- `content.py`：媒体地址校验、受限临时下载和本机语音转写。
- `rag.py`：本机 SQLite 知识库、向量与关键词检索、会话和引用校验。

没有复制原 MCP 服务端、搜索、评论、推荐流、媒体下载、ASR 或 OCR 的实现、运行目录或整个原项目；本项目的内容下载和语音转写集成为独立实现。
