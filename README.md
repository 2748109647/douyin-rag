# 拾藏 · 抖音收藏整理

在本机网页中扫描“收藏－视频”里的视频与图文，使用 OpenAI 兼容模型生成分类和收藏夹名称，预览后执行整理。

## 启动

需要 Python 3.12+、uv，以及本机 Microsoft Edge（Windows 默认使用）。

```powershell
uv sync --frozen
uv run --frozen douyin-rag
```

打开 <http://127.0.0.1:8765>。更换端口：`uv run --frozen douyin-rag --port 8767`。仅监听本机，不需要注册网站或发布到云端。

在网页点击“查看示例”可以体验分类、筛选、改名和批量调整。示例模式不会向抖音发起写入。点击“使用我的收藏”后再连接真实账号。

## 使用步骤

1. **连接与设置**：填写 OpenAI 兼容服务地址、模型名、API 密钥。地址可为服务的 `/v1` 基础地址或完整 `/chat/completions` 地址。本机免密服务可不填密钥。
2. **连接抖音**：点击“打开抖音登录窗口”，在真实抖音网页扫码，返回应用点击“完成登录”。也可填写已有 douyin-mcp 的外部登录状态文件路径；此时以显式配置为准，扫码后如想改用本应用会话，请清空外部路径再保存。
3. **扫描收藏**：遍历全部收藏、收藏夹和夹内作品，按作品 ID 去重并记录原归属。中途失败不会覆盖上次完整快照。
4. **生成分类方案**：模型先根据均匀采样的全量标题设计分类，再逐批给每条作品归类。当前依据标题、描述与作者信息，不下载视频、转写语音或 OCR。内容不足会进入“待复核”或标记低置信度，不声称已经观看内容。
5. **预览**：查看分类依据；修改每条作品的目标分类或收藏夹名称；支持多选批量调整。尚未返回有效结果的作品显示“待分类”。不完整的模型批次不会写入方案。
6. **确认并整理**：确认具体方案后打开抖音窗口，查询/创建目标夹，移动并核对每条作品。只有读到目标成员后才清理旧夹归属。保留原收藏夹对象，不调用取消收藏或删除夹接口。
7. **核对结果**：全部操作后再次遍历目标收藏夹确认覆盖。可以暂停或恢复，中断后的未确认操作先读后写，不盲目重复。重新扫描/分类会将旧快照和方案归档，可在“整理记录”导出。

“全量”指平台实际返回的全部可读作品。隐藏、删除等不可读条目的原始分页提示单独保存；不把可读数量当成账号总收藏数，也不盲目累加可能在多页重复的无效条目数。

## 本机配置与数据

默认运行目录是 Windows 的 `%LOCALAPPDATA%/douyin-rag`，其他系统为 `~/.local/share/douyin-rag`。可通过 `DOUYIN_RAG_STATE_DIR` 自定义。

- 模型设置、密钥、扫描快照、方案和进度写入运行目录，不进入 Git。模型密钥存于本机设置文件，未加密；若不希望落盘，可以使用环境变量。接口和导出的记录均不返回密钥。
- 登录沿用 `DOUYIN_COOKIE`、`DOUYIN_COOKIE_PATH`，或 `XDG_CONFIG_HOME/douyinmcp/cookies.txt`（未配置 XDG 时为 `~/.config/douyinmcp/cookies.txt`）；也支持本应用扫码后的独立浏览器会话。
- `DOUYIN_RAG_API_BASE`、`DOUYIN_RAG_MODEL`、`DOUYIN_RAG_API_KEY` 可提供或覆盖模型配置。不要把真实值放进仓库或粘贴到聊天中。
- `DOUYIN_RAG_BROWSER` 可指定已安装 Chromium 系浏览器的可执行文件；未使用本机 Edge 的环境可运行 `uv run playwright install chromium`。
- 浏览器配置、登录状态文件、模型请求正文不会出现在导出和应用访问日志中。收藏快照本身包含个人收藏信息，按需自行保管。

## 写入范围与验证限制

读取复用 douyin-mcp 的收藏协议和签名实现；新建收藏夹通过真实抖音页面，移动在已登录网页会话内调用收藏夹移动接口，再通过读取接口核对。

这是非官方网页接口。新建按钮、表单或安全 SDK 发生变化，以及验证码、会话失效或风控，都可能中止操作。页面定位不唯一、接口拒绝和写后核对失败时会停止并保留进度，不把尝试写入称为成功。**目前自动化测试使用模拟抖音与模型服务，未对真实账号验证新建收藏夹和移动写入。**第一次实际执行应先核对预览方案，并观察打开的抖音窗口。

## 验证与构建

```powershell
uv run --frozen python -m unittest discover -s tests -v
node --check web/app.js
uv build
```

测试覆盖收藏分页/去重、图文、超长 ID、签名运行时、无效作品提示、模型异常与断点续分、方案修订、账号变化、移动写后核对、进度恢复、归档、密钥脱敏及本机请求边界。不使用真实生产凭据或真实收藏进行测试。

## 代码范围

- `collections.py`：按函数提取的收藏读取与作品整理。
- `signing.py`、`verification.py`、`assets/abogus.js`：读取所需的签名与校验；签名脚本移除了无关前置补丁和演示查询。
- `organizer.py`：扫描、OpenAI 兼容分类、方案编辑、状态与归档。
- `writer.py`：本机浏览器建夹、移动与核对。
- `app.py`、`web/`：本机 API、网页及静态资源。
